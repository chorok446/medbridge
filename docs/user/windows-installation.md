# Windows에 설치하기

## 설치

1. 전달받은 `MedBridge Study_x64-setup.exe` 파일을 두 번 클릭합니다.
2. 파란색 "Windows의 PC 보호" 창이 나타나면(정상적인 경우가 많아요),
   **추가 정보**를 누른 뒤 **실행**을 누릅니다.
3. 설치 안내에 따라 진행합니다. 관리자 암호는 필요하지 않습니다.
4. 설치가 끝나면 시작 메뉴에서 **MedBridge Study**를 실행합니다.

## 처음 실행하면

"MedBridge를 준비하고 있습니다"가 잠시 표시된 뒤 학습자료 화면이 열립니다.

## 프로그램 제거

Windows 설정 → 앱 → MedBridge Study → 제거.
**제거해도 올려 둔 학습자료와 기록은 컴퓨터에 남아 있으며**, 다시 설치하면 그대로
다시 보입니다. 학습자료까지 완전히 지우는 기능은 다음 업데이트에서 제공됩니다.
