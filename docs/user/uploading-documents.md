# PDF 올리기

## 올릴 수 있는 자료

- 강의자료, 의학 논문, 교과서 발췌
- 이름·등록번호 등이 지워진(익명 처리된) 학습용 사례

## 올리면 안 되는 자료

- 실제 환자 이름·등록번호가 있는 기록
- 진료 차트 원본, 검사 결과지 원본

## 올리는 방법

1. "내 학습자료"에서 **PDF 파일 선택**을 누르거나, 파일을 점선 상자에 끌어다 놓습니다.
2. 파일 이름과 크기를 확인합니다. (PDF만 가능, 최대 50MB)
3. "실제 환자를 식별할 수 있는 정보가 포함되어 있지 않음" 항목에 체크합니다.
   체크해야 업로드 버튼이 켜집니다.
4. **업로드**를 누릅니다. 진행 막대로 올라가는 정도를 볼 수 있고, **취소**를 누르면 멈춥니다.

## 올린 뒤

- 잠시 "파일을 확인하는 중"이 표시됩니다. 보통 몇 초면 끝납니다.
- "학습 준비 완료"가 되면 제목을 눌러 문서를 열 수 있습니다.
- 같은 파일을 다시 올리면 새로 만들지 않고 기존 문서를 알려줍니다.

## 문서 관리

- **열기** — 문서와 처리 상태를 봅니다.
- **이름 변경** — 목록에 보이는 제목을 바꿉니다.
- **삭제** — 문서와 파일을 지웁니다. 지우기 전에 한 번 더 물어봅니다.
