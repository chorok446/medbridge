# MedBridge 업데이트하기

MedBridge는 실행할 때 새 버전이 있는지 스스로 확인합니다.

## 업데이트 안내가 나타나면

```text
새 업데이트가 있습니다.
MedBridge 0.1.1
[나중에] [업데이트]
```

- **업데이트**를 누르면 다운로드 진행률이 표시되고, 끝나면 앱이 스스로 다시 시작됩니다.
- 진행 중에는 "MedBridge를 종료하지 마세요" 안내를 따라 주세요.
- **나중에**를 누르면 그대로 계속 사용할 수 있고, 다음 실행 때 다시 안내됩니다.

지금 바로 확인하고 싶으면 **앱 설정 → 업데이트 → 업데이트 확인**을 누르세요.

## 업데이트해도 자료는 안전해요

업데이트 전에 학습자료 기록을 자동으로 백업하며, 업데이트가 실패해도
올려 둔 PDF와 기록은 삭제되지 않습니다.

실패 안내가 나타나면 **다시 시도**를 누르거나, 반복되면 **오류 정보 저장**을 눌러
저장된 파일을 개발자에게 전달해 주세요.
