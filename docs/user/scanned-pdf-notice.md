# 이미지로 된 PDF 안내

스캔하거나 사진으로 만든 PDF는 글자가 "그림"으로 저장되어 있어
MedBridge가 아직 글자를 읽어 낼 수 없습니다.

## 이런 안내가 보여요

- 문서 전체가 이미지인 경우: **"이미지로 된 문서예요"**
- 일부 페이지만 이미지인 경우: 텍스트 확인 → **안내** 탭에
  "이미지로 된 페이지가 있어요 (5쪽, 12쪽…)"로 표시됩니다.
  나머지 페이지의 글은 정상적으로 볼 수 있어요.

## 어떻게 하면 되나요

1. 가능하면 **글자를 선택·복사할 수 있는 PDF**(원본 파일)를 구해서 올려 주세요.
2. 원본이 없는 스캔 자료는 그대로 보관해도 됩니다 —
   이미지 글자를 읽는 기능(추가 처리)은 다음 업데이트에서 제공될 예정이에요.
3. 문서 보기 탭에서는 이미지 페이지도 원본 그대로 볼 수 있습니다.
