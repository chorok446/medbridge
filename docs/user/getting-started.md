# MedBridge Study 시작하기

MedBridge Study는 PDF로 공부를 도와주는 프로그램입니다.
컴퓨터에 설치한 뒤에는 화면의 버튼만 사용하면 됩니다.

## 설치

1. 전달받은 `MedBridge Study 설치 파일(setup.exe)`을 두 번 클릭합니다.
2. 안내에 따라 "설치"를 누릅니다. 관리자 암호는 필요하지 않습니다.
3. 설치가 끝나면 시작 메뉴에서 **MedBridge Study**를 실행합니다.

> 처음 설치할 때 Windows가 "알 수 없는 앱" 경고(SmartScreen)를 보여줄 수 있습니다.
> 전달받은 공식 설치 파일이 맞다면 "추가 정보 → 실행"을 눌러 진행하세요.

## 화면 구성

- **내 학습자료** — 올린 PDF 목록과 처리 상태를 봅니다.
- **앱 설정** — 표시 이름과 학습 수준(설명 난이도)을 바꿉니다.

## 처음 할 일

1. "내 학습자료" 화면에서 **PDF 파일 선택**을 누르거나 파일을 끌어다 놓습니다.
2. "실제 환자를 식별할 수 있는 정보가 없음"을 확인하고 체크합니다.
3. **업로드**를 누릅니다.
4. "파일을 확인하는 중" → "학습 준비 완료"가 되면 문서를 열 수 있습니다.

## 중요한 안내

- 이 프로그램은 **공부를 돕는 도구**입니다. 실제 환자의 진단·처방·응급 판단에 사용하지 마세요.
- 응급 상황에서는 119에 연락하세요.
- 실제 환자 정보가 들어 있는 파일은 올리지 마세요.
