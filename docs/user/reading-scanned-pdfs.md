# 스캔한 PDF 읽기

스캔하거나 사진으로 만든 PDF는 글자가 그림으로 저장되어 있어요.
MedBridge가 그림 속 글자를 읽어 드릴 수 있습니다.

## 사용 방법

1. 문서를 열고 **텍스트 확인 → 안내** 탭으로 이동합니다.
2. "이미지로 된 페이지 N개의 글자를 읽을 수 있어요"가 보이면
   **[이미지 페이지 읽기]** 버튼을 누르세요.
3. "이미지로 된 페이지를 읽는 중입니다. 12 / 38페이지" 진행 상황이 표시됩니다.
   필요하면 **취소**할 수 있어요.
4. 끝나면 본문·구역별 보기에서 읽은 글자를 확인하고, 글자를 누르면
   원본 이미지의 위치가 표시됩니다.

## 알아두면 좋아요

- 한국어와 영어를 함께 읽습니다. 숫자와 단위(mmHg, % 등)도 그대로 보존해요.
- 인쇄 품질이 낮으면 일부 글자를 정확히 읽지 못할 수 있어요 —
  그런 페이지에는 안내가 표시되고 **[다시 읽기]**로 더 정밀하게 다시 시도할 수 있습니다.
- 읽는 동안 다른 문서를 계속 볼 수 있어요.
