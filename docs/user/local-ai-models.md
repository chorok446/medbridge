# 로컬 AI 모델 안내

MedBridge는 내 PC에서 직접 실행하는 로컬 AI로 문서 요약과 질문 답변을 만듭니다. 문서가
외부로 나가지 않습니다.

## 어떤 모델을 고를까요?

- **균형형이 기본 권장입니다.** 대부분의 PC에서 속도와 품질의 균형이 좋습니다.
- **경량형**은 더 가볍고 빠르지만, 복잡한 문서에서는 "근거를 찾지 못했다"며 답변을 더
  자주 보류할 수 있습니다.
- **고품질형**은 품질이 좋지만 메모리와 응답 시간이 더 많이 필요합니다.
- **전문가형**은 가장 높은 품질입니다. 저장 공간을 많이 차지하지만 큰 용량에 비해
  속도가 빠릅니다. 메모리 32GB 이상인 PC에서만 선택하세요.

설정 화면의 "로컬 AI"에서 추천 모델과 예상 저장 공간을 보고 내려받을 수 있습니다.

## 알아두면 좋은 점

- **첫 질문은 더 오래 걸릴 수 있습니다.** 모델을 처음 불러오는 데 시간이 걸리기
  때문이며, 이후 질문은 더 빠릅니다.
- **인터넷이 없어도** 이미 내려받은 모델로 요약과 질문을 사용할 수 있습니다.
- **답변은 업로드한 문서를 기준으로** 만들어집니다. 문서에 없는 내용은 답하지 않고
  보류합니다.
- **답변의 출처를 반드시 함께 확인**하세요. 출처 배지를 누르면 문서의 해당 위치로
  이동합니다.

## 주의

MedBridge는 학습을 돕는 도구입니다. **진단·처방·응급 판단에 사용하지 마세요.** 실제
의료 결정은 반드시 담당 의료진과 확인하세요.
