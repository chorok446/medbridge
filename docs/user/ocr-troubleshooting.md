# 이미지 페이지 읽기 문제 해결

## "일부 글자를 정확히 읽지 못했을 수 있습니다"

- **[다시 읽기]**를 누르면 더 정밀한 방식으로 다시 읽습니다.
- 그래도 부정확하면 원문 이미지와 함께 확인해 주세요. 스캔 품질이 낮거나
  손글씨인 경우 정확히 읽기 어려워요.

## 읽기가 안 되거나 실패해요

1. **[다시 읽기]**를 눌러 보세요.
2. 페이지가 완전히 비어 있으면 "읽을 글자가 없다"고 표시될 수 있어요 — 정상입니다.
3. 반복 실패하면 **앱 설정 → 문제 해결 → 오류 정보 저장**으로 파일을 저장해
   개발자에게 전달해 주세요. (문서 내용은 포함되지 않아요)

## 시간이 오래 걸려요

페이지 수가 많으면 페이지당 몇 초씩 걸릴 수 있어요. 진행 표시를 보면서 기다리거나
**취소** 후 나중에 다시 실행해도 됩니다. 이미 읽은 페이지는 다시 읽지 않아요.
