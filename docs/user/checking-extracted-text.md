# 읽어 낸 글 확인하기

PDF를 올리면 MedBridge가 자동으로 본문을 읽습니다.
"문서 내용을 확인하는 중입니다. 페이지 12 / 38" 같은 진행 안내가 표시되고,
끝나면 **학습 준비 완료**가 됩니다.

## 텍스트 확인 화면

문서를 열고 **텍스트 확인** 탭을 누르면:

- **왼쪽**: 원본 문서. 페이지 이동·확대/축소·회전 버튼이 있어요.
- **오른쪽**: 읽어 낸 글.
  - **본문** — 읽는 순서대로 정리한 글
  - **구역별 보기** — 문단(구역) 단위 목록. **글을 누르면 왼쪽 원본에서 그 위치가
    노란색으로 표시**됩니다. 반대로 원본에서 글 부분을 눌러도 해당 구역이 표시돼요.
  - **표** — 찾은 표 목록. 눌러서 원본 위치를 확인할 수 있어요.
  - **안내** — 이미지로 된 페이지, 읽지 못한 페이지 등 주의사항

## 알아두면 좋아요

- 반복되는 머리글·바닥글(저널명, 쪽 번호)은 본문에서 빼고 정리합니다.
  "반복되는 머리글·바닥글도 표시"를 켜면 함께 볼 수 있어요.
- 원본 그대로 보고 싶으면 본문 탭에서 "정리하지 않은 원문 그대로 보기"를 켜세요.
- 읽기에 실패하면 **다시 시도** 버튼으로 한 번 더 시도할 수 있습니다.
