# 문제가 생겼을 때

## "파일을 처리하지 못했습니다"가 보여요

문서 옆의 안내를 먼저 읽어 보세요. 가장 흔한 원인은 다음과 같습니다.

| 안내 문구 | 해결 방법 |
|---|---|
| 암호로 보호되어 있습니다 | PDF의 암호를 해제한 뒤 다시 올려 주세요 |
| 손상되었을 수 있습니다 | 파일을 다시 저장하거나 다른 파일을 올려 주세요 |
| PDF 형식이 아닙니다 | PDF 파일인지 확인해 주세요 (한글·워드 문서는 PDF로 저장 후 업로드) |
| 파일이 너무 큽니다 | PDF를 나누어 50MB 이하로 올려 주세요 |

**다시 시도** 버튼을 누르면 같은 파일을 한 번 더 확인합니다.

## 업로드가 되지 않아요

1. 파일이 PDF인지, 50MB 이하인지 확인하세요.
2. "실제 환자를 식별할 수 있는 정보가 없음" 체크박스에 체크했는지 확인하세요.
3. 앱을 완전히 종료했다가 다시 실행해 보세요. 올려 둔 자료는 사라지지 않습니다.

## 화면이 이상하거나 멈췄어요

앱을 종료하고 다시 실행해 보세요. 학습자료와 기록은 컴퓨터에 안전하게 저장되어 있습니다.

## 그래도 해결되지 않으면

문서 옆의 **오류 신고** 버튼을 눌러 주세요. 신고 내용은 개발자가 확인합니다.
급한 경우에는 앱을 전달해 준 사람에게 연락해 주세요.
