# Windows 실기기 검증 테스트 키트 사용 안내

`docs/testing/windows-test-kit/` 안의 7개 PDF는 실제 환자 정보가 전혀 없는 합성 파일입니다(코드로 생성). `docs/testing/windows-sprint2-validation.md`의 각 체크리스트 항목에 이 파일들을 매칭해 두었으니, 순서대로 따라가며 체크박스를 채우면 됩니다.

## 준비

1. GitHub Actions에서 `medbridge-windows-setup` 아티팩트를 내려받아 Windows 10/11 PC에 복사
   - https://github.com/chorok446/medbridge/actions/runs/30616849579 → Artifacts
2. `docs/testing/windows-test-kit/` 폴더 전체를 같은 PC로 복사 (USB, 클라우드 드라이브 등)
3. 설치 전 확인: Python·Node·Git·Docker가 없는 일반 사용자 계정에서 진행 (개발 도구 유무는 앱 동작에 영향이 없어야 함)

## 항목별 실행 순서

### 준비물 / 설치 (§2, 1~4번)

| # | 항목 | 사용 파일 | 확인 방법 |
|---|---|---|---|
| 1 | NSIS 설치, 관리자 권한 불필요 | — | 일반 사용자 계정에서 setup.exe 더블클릭 → 설치 마법사가 관리자 승격 창(UAC) 없이 끝나는지 |
| 2 | 개발 도구 없는 환경 실행 | — | 설치 후 앱 실행 → 정상 기동(시작 화면 → 목록 화면) |
| 3 | 한국어 사용자명 경로 | `01_digital_simple.pdf` | 한글 Windows 계정명(예: `홍길동`)으로 로그인 후 앱 실행 + 이 파일 업로드까지 성공하는지 |
| 4 | 공백 포함 경로 | `01_digital_simple.pdf` | 계정명 또는 앱 설치 경로에 공백이 있는 환경에서 동일 확인 |

### Sprint 2B 추가 검증 (§22 — OCR)

| 확인 사항 | 사용 파일 | 확인 방법 |
|---|---|---|
| 한국어 스캔 PDF → [이미지 페이지 읽기] → 결과 확인 → 클릭 하이라이트 → 재실행 유지 | `05_scanned_korean_short.pdf` | 업로드(상태: "이미지로 된 문서예요") → [안내] 탭 → [이미지 페이지 읽기] → 완료 후 "심장은 혈액을…" 등 한국어가 정확히 읽히는지 → 블록 클릭 하이라이트 → 앱 재실행 후 결과 유지 |
| 오프라인 상태 확인 | — | Wi-Fi/네트워크 끈 상태에서 위 OCR 흐름이 정상 동작하는지 (로컬 Tesseract이므로 인터넷 불필요해야 함) |
| Tesseract 미설치(번들 손상 등) 시 동작 | — | 정상 설치본에서는 해당 없음. 필요 시 `%LOCALAPPDATA%`의 앱 리소스 폴더에서 tesseract.exe를 임시로 이름 변경 후 실행 → "이미지 페이지 읽기를 사용할 수 없다"는 안내가 나오는지(크래시 없이) |
| 50p+ 혼합 PDF | `07_mixed_50pages.pdf` | 업로드 후 상태가 "본문을 읽었습니다 (일부 페이지 제외)"로 표시되는지, 디지털 페이지는 즉시·스캔 페이지는 OCR 후 읽히는지 |
| OCR 중 취소 | `06_scanned_korean_long.pdf` (6쪽) | [이미지 페이지 읽기] 실행 직후 [취소] 클릭 → 진행 중이던 페이지 이후가 깨끗이 멈추는지, 문서가 이상 상태로 남지 않는지 |
| OCR 중 강제 종료 후 복구 | `06_scanned_korean_long.pdf` (6쪽) | [이미지 페이지 읽기] 실행 중 작업 관리자로 앱 강제 종료 → 재실행 시 자동으로 이어서 처리되거나, 최소한 무한 "처리 중" 상태로 고착되지 않는지 |
