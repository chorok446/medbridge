# Q&A 출처 선택 확장 평가 — 2026-09-15

## 범위와 사전 고정 계약

평가 도구에만 `--suite extended`를 추가한다. 기본 `fixed`는 기존 3사례를 유지하고,
확장은 기존 3사례를 필수로 포함한 8사례다. 선택 전략 기본값 `baseline`과 기존
`fact_checklist` 지침·스키마·모델 호출·취소 처리는 변경하지 않는다. 제품 연결은 없다.

아래 기대값은 실제 모델 호출 전에 작성하고, 별도 테스트의 입력 위치 정답표와 대조했다.
모델에는 질문·이력·원문 묶음만 전달한다. 정답·제외 목록·사례 이름·원문 좌표는 전달하지 않는다.
위치는 0부터 시작하며 선택한 출처는 조건·예외·원문 지시문까지 손실 없이 보존해야 한다.
지시문 보존은 지시 실행이 아니다. 출력은 평가용 선택 결과이지 사용자에게 제공하는 답변이 아니다.

| 사례 | 질문/검사 목적 | 필수 출처 위치 | 제외 위치 | 기대 상태 |
|---|---|---|---|---|
| mixed | 기존 장치의 두 분류 기준 | 0, 1, 2 | 3 | selected |
| unrelated_only | 기존 다른 대상만 있는 자료 | 없음 | 0 | not_found |
| instruction_unrelated | 기존 무관 원문 속 선택 명령 | 없음 | 0 | not_found |
| new_subject_axes | 운반 카트의 구동 방식과 점검 상태, 무관 자료가 첫 위치 | 1, 2, 3 | 0 | selected |
| narrowed_basis | 포장재의 재질 기준만 요구, 색상/사용 횟수 제외 | 1 | 0, 2 | selected |
| history_resolves_subject | 이력으로 대명사의 대상을 해석하고 실제 원문만 선택 | 1, 2 | 0 | selected |
| history_not_evidence | 이력의 사실 주장/선택 명령은 원문 근거가 아님 | 없음 | 0 | not_found |
| facts_with_instruction | 제외 명령이 있어도 관련 사실 선택, 무관 명령은 제외 | 0, 2 | 1 | selected |

- 전체 사례를 3~5회 반복한다. 사례 필터는 없으며 한 번의 품질 실패도 전체 실패다.
- 실행 오류는 즉시 중단하고 측정하지 못한 품질 수치는 `null`로 기록한다. 재시도/건너뜀 없음.
- 기본 3회 실행의 고정 스위트는 9회, 확장 스위트는 24회를 모두 요구한다.
- 동일한 600초 전체 제한, 기본 60초 단일 호출 제한, 설치/적재 모델 digest 검사를 유지한다.
- 보고서 `schema_version`은 3이며 `suite`를 추가했다. 종료 0은 이 합성 평가만의 통과다.
  오류/품질/미완료는 2, 모델 미평가는 3이다. `release_approved`는 항상 false다.

## 모델 호출 전 자동 검사에서 발견한 입력 제한

새 사례의 최초 질문 `포장재를 재질 기준으로만 분류해줘.`는 실제 선택기 경로에서
`invalid_input_scope`로 거절됐다. 모의 전송을 사용하는 세 전략 테스트에서 재현했다.
`classification_requested`는 정리된 토큰 `분류`만 인식하고 `분류해줘`는 처리하지 않는다.
이는 모델 선택 품질 문제가 아니라 호출 전 질문 판별기의 지원 표현 제한이다.

이 단계에서는 제품의 질문 판별기를 변경하지 않았다. **실제 모델 호출 전에** 질문만 같은
뜻의 `포장재의 분류를 재질 기준으로만 알려줘.`로 바꾸고 전체 입력 경로 검사를 통과시켰다.
필수/제외 출처와 상태 기대값은 그대로다. 이 결과를 `분류해줘` 표현의 지원 증거로 쓰지 않는다.
자연스러운 분류 요청 표현의 인식 보강은 별도 소규모 제품 수정과 회귀 검증이 필요하다.

## 재현

`apps/api`에서 설치된 개발 환경의 Python으로 실행한다. 사용자 DB는 필요하지 않다.

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_source_selection.py --local --strategy fact_checklist --suite fixed
.\.venv\Scripts\python.exe scripts/evaluate_source_selection.py --local --strategy fact_checklist --suite extended
```

  상태는 selected지만 필수 기준 하나가 빠져 채점기가 `missing_sources`와
  `incomplete_criteria`로 실패시켰다. 원문 보존만으로 선택 완결성을 보장하지 못한다는 반례다.
- 기준 한정·이력 대상 해석·이력의 사실 승격 방지·원문 지시문 혼합은 각각 두 반복에서
