## 해결한 평가의 빈틈

이전 임시 비교는 `expected_selection=false`를 출력하고도 정상 종료할 수 있었다.
일부 기준을 빠뜨린 `selected` 결과나 지시문이 섞인 무관 자료 선택은 원문 보존 검사만으로
검출되지 않았다. 모델이 자기 결과를 평가하거나 단순 선택 개수만 비교해서는 부족했다.

- 고정 비의료 합성 3사례를 코드에 정의한다: 장치의 전압/진행 단계 + 색상 자료, 무관 색상만,
  선택 지시문이 포함된 무관 색상 자료. 각 사례의 필수 기준·출처·제외 자료·상태를 따로 명시한다.
- 정답표는 모델 입력 밖에 둔다. 실제 선택기의 질문·원문·묶음만 전달하고 별도 사본으로 채점한다.
  정답을 응답으로 대신 내보내거나 모델에 정답 출처를 알려 주지 않는다.
- 필요한 각 기준의 모든 출처, 제외할 출처, 정확한 상태를 대조한다. 같은 수의 출처를 골라도
  다른 자료로 바꿔 고르면 누락과 오선택을 각각 실패로 센다. 무근거 사례는 `not_found`를 요구한다.
- 원문·해시·좌표·문자 범위·조건을 독립 비교하며 잘린 원문, 변조된 출처, 중복, 순서 변경,
  묶음 일부 선택도 실패다. 입력 정답표의 누락/중복/불일치는 채점에 사용하지 않는다.
- 전체 3사례 × 3~5회 반복의 정확한 집합을 요구한다. 사례 필터, 반복 누락/중복, 한 번의 실패를
  나머지 통과나 마지막 결과로 덮을 수 없다. 게이트 통과에도 `release_approved=false`다.

이는 **이 세 합성 사례의 기대값에 대한 회귀 평가**다. 임의 실제 문서에서 올바른 분류를
알아내는 판별기, 문서 그룹화 추론, 의료 의미 검증이나 제품 출시 게이트를 대체하지 않는다.

## 실행 및 자동화 계약

API 폴더의 기존 환경에서 실행한다.

```powershell
.venv/Scripts/python.exe -X utf8 scripts/evaluate_source_selection.py --local --repeat 3 --timeout 60
```

- `--local` 명시가 있어야 실행한다. qwen3:8b 고정, 자동 설치/다운로드 없음.
- 전체 사례만 실행하며 반복은 3~5회, 호출 제한은 0초 초과~180초, 전체 실행 제한은 600초다.
- `0`: 고정 합성 스위트 통과, **출시 승인 아님**. `2`: 품질·완결성·실행 실패.
  `3`: 모델 전제 미충족으로 미평가. 스킵/미완료를 성공으로 반환하는 옵션은 없다.
- 실행 예외는 즉시 중단하고 후속 반복을 시도하지 않는다. 미측정 개수는 0 대신 null이다.
  단계·허용된 오류 종류/범주만 기록하며 예외 원문·모델 산문·원문·내부 경로는 내보내지 않는다.
- 실제 적재 모델과 설치 digest를 확인하며 변경/조회 실패도 통과를 막는다.
  JSON은 집계·고정 합성 사례 ID·합성 출처 번호만 포함한다. stdout 이외 파일/DB 쓰기는 없다.
- 일반 CI에는 로컬 모델 호출을 추가하지 않았다. 새 결정론적 단위 테스트는 기존 API 테스트에서 돈다.
  이 스크립트는 수동 평가나 후속 자동화가 종료 코드로 품질 실패를 감지할 때 사용한다.
