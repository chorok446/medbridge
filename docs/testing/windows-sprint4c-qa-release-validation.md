# Sprint 4C-B — Windows 실기기 Q&A 출시 검증 체크리스트

실제 설치 파일과 GUI로, 개발 지식이 없는 사용자가 로컬 AI를 설치·활성화하고 출처 기반
Q&A를 안정적으로 쓸 수 있는지 확인한다. AI는 GUI를 조작할 수 없어 이 단계를 대신할 수 없다.

## 기록 항목 (각 실행 공통)

- 앱 버전 / 커밋 SHA / Windows 버전 / RAM / CPU / GPU / Ollama 버전 / 모델명
- 첫 로드(cold) 시간 / warm 응답 시간
- 각 항목 결과: 통과 / 실패 / 보류, 비고, 스크린샷 파일명

## 설치·모델

1. 관리자 권한 없이 MedBridge 설치
2. Ollama 미설치 상태 안내 표시
3. 공식 설치 페이지 열림(외부 브라우저)
4. Ollama 설치 후 "다시 확인" → 준비됨 전환
5. qwen3:8b 다운로드 시작
6. 다운로드 진행률·단계 정확
7. 다운로드 취소 동작
8. 취소 직후 중복 다운로드 차단
9. 워커 종료 후 다시 다운로드 가능
10. 모델 설치 완료가 실제 설치 목록으로 검증됨
11. 연결 테스트 성공 문구
12. 모델 활성화(기본 모델로 사용)

## Q&A

13. 한국어 디지털 PDF 질문
14. 영어 PDF에 한국어 질문
15. 표 수치 질문(정확한 셀 값)
16. 자료에 없는 질문 → 보류
17. 부정 문장 질문(극성 보존)
18. 상충 근거 질문(양쪽 출처 표시)
19. 스트리밍 중 출처 배지 표시
20. 출처 클릭 시 PDF 위치 이동
21. 답변 생성 취소
22. 취소 후 새 질문 가능
23. 앱 강제 종료
24. 재실행 후 interrupted 상태 표시
25. 중단된 질문 재시도
26. OCR·청크 재생성 중 revision 차단(이전 답변 저장 안 됨)
27. 외부 AI 동의 없이 로컬 모델 사용
28. 인터넷 끊긴 상태에서 로컬 모델 사용

## 안정성

29. 10회 연속 질문(스레드 잠금·고아 작업 0)
30. 긴 답변에서 UI 멈춤 없음
31. 모델 다운로드 후 앱 재시작
32. Ollama 종료 시 안전 오류(포트·stack trace 없음)
33. Ollama 재실행 후 복구
34. MedBridge 종료 후 sidecar·외부 연결 잔류 없음
35. 작업 관리자에서 비정상 메모리 증가 없음
36. 재설치·업데이트 후 모델 설정·Q&A 기록 유지

## 자동 평가 연계

실기기 검증 전에 Layer 2 자동 평가를 먼저 통과하는 것을 권장한다:

```
uv run python scripts/evaluate_local_qa.py --model qwen3:8b --repeat 3 --fail-on-gate
```

Ollama·모델이 없으면 평가는 자동 다운로드 없이 skip된다.
