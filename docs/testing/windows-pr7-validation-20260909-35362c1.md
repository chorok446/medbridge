### 새 출시 차단 문제: 원문 밖 설명을 supported로 저장

재시도 동작은 완료됐지만 답변의 근거 충실도는 실패했다. 긴 답변에서 아래 두 설명에
출처 배지 3·5가 붙었으며 DB의 해당 claim도 `supported`, 출처 1·2쪽으로 저장됐다.

- 혈액이 “산소와 영양분을 운반”한다는 설명.
- 근육이 “수축과 이완을 통해 혈액을 펌프”한다는 설명.

해시로 한정한 같은 합성 PDF의 두 페이지 추출 원문을 읽기 전용으로 대조했다.
원문은 제목·쪽수·문단 번호와 “심장은 온몸에 혈액을 보내는 근육 기관이다”의 반복뿐이며
산소·영양분·수축·이완 설명은 없다. 일반 지식의 참·거짓이 아니라 **문서가 뒷받침하지
않는 내용을 문서 근거가 있는 것처럼 표시한 실패**다. 실제 환자 판단이나 치료는 없었다.
재시도 이전의 긴 답변에서도 같은 종류의 확장이 보였다.

![재시도 완료 답변의 원문 밖 설명과 출처 배지](screenshots/pr7-35362c1-retry-unsupported.jpg)

다음 제품 수정에서는 이 합성 사례를 회귀 테스트에 추가하고, 원문 인용이 포함됐다는
이유로 같은 claim의 추가 설명까지 근거 있음으로 통과하는 경로를 조사해야 한다.
원인은 아직 확정하지 않았고, 평가 임계치나 출처 검증을 완화하지 않는다.
패널 잘림보다 이 근거 충실도 문제를 우선한다. 초기 모델 평가의 통과는 이 새 실패를
무효화하지 않으며, 수정 후 실제 모델 평가와 Windows 설치본 재검증이 필요하다.
