# OCR 품질 정책과 한계

## 품질 집계 (페이지 단위, ocr_runs 저장)

평균·중앙값 confidence, 낮은 신뢰 단어 비율(<0.60), 단어 수, 처리 시간.
confidence 숫자는 사용자 화면에 표시하지 않는다.

| 판정 | 조건 | 사용자 표시 |
|---|---|---|
| ocr_completed | 정상 | "이미지 페이지 읽기가 끝났어요" |
| ocr_low_confidence | 낮은 신뢰 비율 > 30% | "일부 글자를 정확히 읽지 못했을 수 있습니다. 원문과 함께 확인해 주세요." + [다시 읽기] |
| ocr_empty | 단어 < 3 | 빈 페이지 안내 |
| ocr_failed | 실행 실패/timeout | [다시 읽기] |
| ocr_cancelled | 사용자 취소 | 재시작 가능 |

## 알려진 한계

- 필기체 미지원 · 저해상도 스캔(원본 <180dpi 경고) 정확도 하락 · 복잡한 표 구조 복원 불가
  (텍스트만) · 수식/위첨자 부정확 · 심하게 기울어진 문서(deskew 전처리는 후속) ·
- 합성 fixture 한계: PyMuPDF 내장 CID 한글 폰트는 소형 글자 자간이 비정상적이라 소형 한글
  인식률이 실제 스캔 문서보다 낮게 측정됨 — 정확도 검증의 기준은 Windows 실기기 실문서 검증
- 재시도는 고품질 모드(400dpi)로 실행된다
