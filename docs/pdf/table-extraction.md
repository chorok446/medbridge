# 표 추출

1차 도구: PyMuPDF `page.find_tables()` (규칙 기반, AI 해석 없음).

## 저장 (`document_tables`)

페이지 좌표 bbox · 행/열 수 · 셀 텍스트(cells_json) · Markdown 표현 ·
추출 상태(extracted/failed) · 신뢰도(기본 0.7) · 표와 겹치는 본문 블록은
`is_table` 플래그로 연결(본문 중복 방지).

## 실패 격리

- 표 하나의 추출 실패 → 해당 표만 `failed` 행으로 기록, 페이지는 계속 처리
- 표 탐지 전체 실패 → 페이지 추출은 정상 진행

## 한계와 사용자 안내

병합 셀·경계선 없는 표는 정확도가 낮다. 신뢰도 <0.8 또는 실패 상태인 표는 GUI에
다음 문구를 표시한다:

> 표의 일부 내용을 정확히 읽지 못했을 수 있습니다. 원문과 함께 확인해 주세요.

표 내용에 대한 의학적 해석은 하지 않는다.
